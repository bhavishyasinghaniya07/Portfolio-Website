# Developer Portfolio Website

A personal portfolio website built using React to showcase projects, skills, and contact information. Designed with a clean UI and responsive layout to provide a professional and user-friendly experience.

---

## Features

* **Responsive Design**
  Fully responsive layout compatible with all screen sizes.

* **Project Showcase**
  Displays featured projects with descriptions, tech stacks, and GitHub/demo links.

* **About Section**
  Includes personal background, skills, and career goals.

* **Contact Form**
  Simple and functional contact form for professional outreach.

* **Smooth Navigation**
  Modern UI with smooth scrolling and route-based navigation.

---

## Tech Stack

* **Frontend:** React.js
* **Styling:** Tailwind CSS
